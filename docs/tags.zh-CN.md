# HCML 标签与 HTML 标签映射表

> 本文档把 HCML 中所有可用的**中文标签名**和**中文属性名**，
> 对应到它们在浏览器中最终被渲染成的 **HTML 英文标签 / 属性**。
> 同一个 HTML 标签可以有**多个中文别名**（都表示同一个东西）。
> 未识别的中文标签会被降级成纯文本，不会破坏页面结构。
